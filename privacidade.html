Política de Privacidade

Última atualização: 19 de novembro de 2026

Esta política explica quais dados o Pixel Perdido Publisher (o "App") trata. O App é uma ferramenta privada, usada só pelo dono do canal Pixel Perdido para enviar os vídeos do próprio canal à conta do TikTok do dono, como rascunhos.

1. Dados que recebemos do TikTok

  • Tokens de acesso e de renovação emitidos pelo TikTok quando o dono autoriza o App, usados só para chamar a API do TikTok em nome do dono.
  • Informações básicas da conta (open ID, nome de exibição e foto), usadas só para confirmar qual conta está conectada.
  • Status do envio de cada vídeo devolvido pelo TikTok (por exemplo, se o rascunho foi recebido).

O App não acessa seguidores, mensagens, comentários, métricas nem dados de outros usuários do TikTok.

2. Como usamos

Só para enviar os vídeos do Pixel Perdido aos rascunhos do TikTok do dono e mostrar a ele o resultado do envio. Não usamos os dados para publicidade, perfilamento nem qualquer outro fim.

3. Armazenamento e segurança

Os tokens ficam guardados no servidor privado de produção do canal, num arquivo que só o usuário de sistema do App pode ler, e nunca são publicados, registrados em texto aberto nem compartilhados. Os vídeos e textos ficam no mesmo servidor enquanto são produzidos e revisados.

4. Compartilhamento

Não vendemos, alugamos nem compartilhamos dados com terceiros. Os dados vão só para o TikTok, pela API oficial, para fazer o envio pedido pelo dono.

5. Retenção e exclusão

Os tokens ficam guardados enquanto a conexão estiver ativa e são apagados quando o acesso é revogado ou a pedido. O acesso pode ser revogado a qualquer momento no app do TikTok (Configurações e privacidade → Segurança e permissões → Gerenciar permissões de apps). Pedidos de exclusão podem ser feitos pelo canal de contato e são atendidos em até 30 dias.

6. Crianças

O App não é voltado a crianças e é usado só pelo dono adulto do canal.

7. Mudanças

Esta política pode ser atualizada; a data no topo indica a versão mais recente.
